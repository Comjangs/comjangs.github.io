# Seamless Localization

Extends the official Unity Localization package with flicker-free locale font switching for TextMesh Pro texts and dropdowns, one-click setup with default fonts, editor previews, and a converter for existing texts.

## Requirements
- Unity 6000.0 or later
- Localization 1.5.13 or later
- Unity UI 2.0.0 or later (includes TextMesh Pro)

If a required package is missing or too old, the tool stays inactive without compile errors and asks to install it. You can also run **Tools > Seamless Localization > Install Required Packages**.
