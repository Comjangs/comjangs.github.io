# Glossary

The UI, log messages, and this documentation use only these terms.

| Term | Meaning |
|---|---|
| Locale | A language (and optional region) defined in the Localization settings, e.g. `en`, `ja-JP`. |
| Font Table | An Asset Table Collection that holds one TextMesh Pro font asset per locale for each font role. |
| Font Role | The purpose of a font, such as body text or titles. Each font role is a key in the font table, e.g. `Font.Body`. |
| Default Font Role | The font role assigned to newly added text components. |
| Font Slot | One cell of the font table: a font role for a locale. |
