# Seamless Localization

공식 Unity Localization 패키지를 보강합니다. TextMesh Pro 텍스트와 드롭다운의 로케일별 폰트를 깜빡임 없이 바꾸고, 기본 폰트까지 한 번에 준비하는 셋업, 에디터 미리보기, 기존 텍스트 변환기를 제공합니다.

## Requirements
- Unity 6000.0 이상
- Localization 1.5.13 이상
- Unity UI 2.0.0 이상(TextMesh Pro 포함)

필수 패키지가 없거나 버전이 낮으면 컴파일 오류 없이 도구가 비활성 상태로 남고 설치를 물어봅니다. **Tools > Seamless Localization > Install Required Packages**로 직접 실행할 수도 있습니다.
