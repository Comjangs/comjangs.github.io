# 용어집

UI, 로그 메시지, 이 문서는 아래 용어만 씁니다. UI가 영어라서 용어도 영어 그대로 씁니다.

| 용어 | 뜻 |
|---|---|
| Locale | Localization 설정에 정의된 언어(와 지역)입니다. 예: `en`, `ja-JP`. |
| Font Table | 폰트 역할마다 로케일별 TextMesh Pro 폰트 에셋을 하나씩 담는 Asset Table Collection입니다. |
| Font Role | 본문, 제목처럼 폰트의 용도입니다. 폰트 역할은 각각 폰트 테이블의 키입니다. 예: `Font.Body`. |
| Default Font Role | 새로 추가하는 텍스트 컴포넌트에 지정되는 폰트 역할입니다. |
| Font Slot | 폰트 테이블의 한 칸, 즉 한 로케일의 한 폰트 역할입니다. |
